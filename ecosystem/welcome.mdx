# Agent infrastructure, built in the open

<div className="rosso-intro">

rossoctl is an open source research project building the infrastructure AI coding agents need to run
for real: a dense runtime where sessions resume exactly where they left off, a proxy that shows what
your coding agent sends and what it costs, an event-driven wake path, automated benchmarking, and
state management for distributed agents. Around that core we work on context, access control, and
data governance, and we run the org itself on the automation we build.

</div>

## Past activities

Our earlier platform direction, shipped through v0.8: a data plane that mediated what agents do,
and a set of services agents could call. The cards below are the historical record — where the work
continues, each card points at the repository it lives in today; the rest we decided not to continue.

### The data plane (Rosso Cortex)

An intercept sitting transparently between an agent and everything external it touches: models,
tools, users, and other agents. From that one vantage point it enforced the guarantees agents
can't enforce for themselves.

<Accordion items={pastDataPlane} />

### Services

The building blocks agents needed to do real work: skills, tools, memory, knowledge bases, and
sandboxes.

### The old repositories

The repositories that carried this direction are archived — read-only, but still available:

| Repository | What it was |
| --- | --- |
| [operator](https://github.com/rossoctl/operator) | Kubernetes operator for deploying and lifecycle management of agents and tools |
| [examples](https://github.com/rossoctl/examples) | Sample agents and tools for the rossoctl platform |
| [OpenShell](https://github.com/rossoctl/OpenShell) | The safe, private runtime for autonomous agents — the sandbox layer |
| [openshell-driver-openshift](https://github.com/rossoctl/openshell-driver-openshift) | OpenShell compute driver that provisioned agent sandboxes on OpenShift |
| [openshell-credentials-keycloak](https://github.com/rossoctl/openshell-credentials-keycloak) | OpenShell credentials driver for Keycloak |
| [workload-harness](https://github.com/rossoctl/workload-harness) | Tools for generating workloads against agents |
| [lab-runtime-simulation](https://github.com/rossoctl/lab-runtime-simulation) | Virtual MCP server for validating tool calling before and during runtime |
| [lab-clear](https://github.com/rossoctl/lab-clear) | Trajectory analysis and deep insights on agent failures |
| [DEPRECATED-kagenti-bundle-service](https://github.com/rossoctl/DEPRECATED-kagenti-bundle-service) | Bridged Kubernetes-native policy definitions to the OPA bundle protocol |
