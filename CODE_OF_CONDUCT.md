# Code of Conduct

The rossoctl Code of Conduct is maintained in the main project repository:

**→ [rossoctl/rossoctl/CODE_OF_CONDUCT.md](https://github.com/rossoctl/rossoctl/blob/main/CODE_OF_CONDUCT.md)**

It applies to every repository, issue tracker, pull request and communication channel in the
[rossoctl organization](https://github.com/rossoctl).

GitHub serves this file to any rossoctl repository that does not define its own, so the policy
is written once and inherited everywhere rather than copied and left to drift.

## Reporting

Reporting addresses and the enforcement process are in the document linked above; conduct
concerns are handled by the maintainers listed in
[MAINTAINERS.md](https://github.com/rossoctl/rossoctl/blob/main/MAINTAINERS.md). See also
[GOVERNANCE.md](https://github.com/rossoctl/rossoctl/blob/main/GOVERNANCE.md) for how
enforcement decisions are made.
